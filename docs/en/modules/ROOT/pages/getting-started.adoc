= Getting started
:description: First JSON-B 3.0 mapping generated at compile time by Champollion.

== Prerequisites

* **Java 25**, **Maven 4.0.0-rc-5** — `.sdkmanrc` at the repo root.

== Maven coordinates

[source,xml]

== Hello world

Define a type:

[source,java]
----
package io.example;

import jakarta.json.bind.annotation.JsonbProperty;

public record Order(
    @JsonbProperty("orderId") long id,
    String customer,
    java.util.List<Item> items
) {}

public record Item(String sku, int quantity, double price) {}
----

Serialize:

[source,java]
----
import jakarta.json.bind.Jsonb;
import jakarta.json.bind.JsonbBuilder;

void main() {
    var jsonb = JsonbBuilder.create();
    var order = new Order(42L, "Vauban", java.util.List.of(
        new Item("PIK-01", 2, 19.50)
    ));

    String json = jsonb.toJson(order);
    System.out.println(json);

    Order back = jsonb.fromJson(json, Order.class);
    assert back.id() == 42L;
}
----

== Under the hood

At compile time, `champollion-codegen-apt` emitted under `target/generated-sources/` an `Order_Binding` that knows how to read and write `Order` without reflection. At runtime, `JsonbBuilder.create()` enumerates bindings via `ServiceLoader` and merely invokes them.

== Build and run

[source,bash]
----
sdk env
./mvnw -ntp install -DskipTests
java -jar target/myapp.jar
----

[TIP]
====
For external types you cannot annotate, use `champollion-codegen-maven-plugin` with a list of target classes in the plugin configuration.
====
