# Champollion protobuf — Conformance Google expected failures
# ============================================================
#
# Cette liste recense les tests de conformance Google que Champollion ne
# supporte pas et qui doivent être traités comme "expected failure"
# (n'impactent pas le score 100% PASS du périmètre supporté).
#
# Cf. ADR docs/adr/0001-jspb-text-format-out-of-scope.md pour le rationnel.
#
# Catégories couvertes :
#
# 1. WKT Struct/Value/ListValue/NullValue (proto3 §google.protobuf.{Struct,Value,ListValue})
#    Non implémentés — sealed hierarchy de Value est un chantier dédié
#    (M6 ROADMAP). Couvre RepeatedValue, RepeatedListValue, Struct*, ValueAccept*.
#
# 2. WKT Any avec contenu complexe (Any.JsonInput.Any*)
#    Roundtrip Any nécessite résolution de type dynamique à la
#    désérialisation — TypeRegistry partiel actuellement. À industrialiser.
#
# 3. Enum aliasing (allow_alias = true)
#    Notre @ProtobufField utilise Java enum ordinals — pas de support multi-name
#    pour une même value proto. EnumFieldWithAlias* attendus en failure.
#
# 4. NEG enum value (proto value = -1)
#    NestedEnum.NEG = -1 mappé en Java enum ordinal=3 — désynchronisation.
#    Nécessite annotation @ProtoEnumValue(-1) sur la constante Java (M6).
#    Couvre ValidDataScalar.ENUM[3-4], ValidDataRepeated.ENUM.*, MissingDefault.
#
# 5. UnknownFieldSet preservation (UnknownOrdering, UnknownVarint, UnmatchedEndGroup*)
#    Notre runtime drop les unknown fields à la sérialisation. Spec exige
#    forward-compat. Chantier dédié M6 — RuntimeBinding doit injecter un
#    UnknownFieldSet record component et le ré-émettre.
#
# 6. MessageSetEncoding (proto2 extensions)
#    Format MessageSet legacy (proto2 only, internal Google). Non priorité.
#
# 7. Merge sémantique (RepeatedScalarMessageMerge, ValidDataOneof.MESSAGE.Merge)
#    Le wire format permet à plusieurs messages d'un même field d'être mergés
#    (spec proto3 §field-message merge). Notre code écrit le dernier reçu sans
#    merger les sous-fields. À implémenter.
#
# 8. Uint64QuotedExponentFieldTooLarge
#    UINT64 quoted exponent > 2^64-1 doit fail. Notre BigDecimal accept
#    silently — fix mineur à venir.
#
# 9. EnumFieldUnknownValue.Validator
#    Le validator dans le runner Google attend qu'on émette un message JSON
#    valide pour un unknown enum value. Notre code émet null (skippé du JSON).
